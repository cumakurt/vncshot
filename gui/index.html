    About

    vncshot dev is a local RFB survey bench. It listens on loopback and does not require root.

    Keyboard: Ctrl+K or Cmd+K opens search. ? lists shortcuts. G then D, F, H, S or N jumps.

    Authorized use only. Scan only networks you own or have explicit written permission to test. Captured desktops are sensitive evidence; report findings only to the network owner. The developer accepts no liability for use or misuse of this tool. See LICENSE for the full terms.
